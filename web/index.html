ARCHITETTURA · NAIL 0.54

Cinque forme per un linguaggio

Nail riduce le espressioni a cinque costruttori. Non è una semplificazione didattica: è il suo vero Core AST.

I costruttori

Literal
Un valore immediato.
Var
Un nome da risolvere nell'ambiente.
Lambda
Una funzione con un parametro e un corpo.
Apply
L'applicazione di una funzione a un argomento.
If
La scelta tra due espressioni.

Provalo davvero

Il programma definisce una funzione identità e la applica al valore true. Eseguilo nell'editor, poi osserva l'espansione e l'analisi dei tipi.

nail 0.54 ;
def identityLab x = x ;
identityLab true ;
